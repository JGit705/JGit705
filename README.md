## About

I run daily dispatch for a **140+ van fleet across Central and West London** at Ocado Logistics: live scheduling, incident handling, and keeping delivery performance on target.

My background is a **BEng (Hons) in Mechanical Engineering, IMechE accredited**, in CAD, FEA and CFD. It taught me to model the system, test the assumption and measure the result. I now bring the same approach to software, building tools on real data that are honest about what the data can and cannot tell you.
